# Input and coordinate contracts

`SignalBatch.data` contains already prepared floating-point tensors shaped `[trial, sensor, patch, sample]`. EEGLens does not infer units, filters, channel aliases, references or resampling. Record the actual recipe in `preprocessing_id` and `unit`; matching strings are provenance checks, not verification that preprocessing was performed correctly. Trial IDs and channel names must be unique, nonempty strings matching their axes; data must be finite and all axes nonempty.

`patch_stride_samples` describes the distance between successive patch starts; the default equals the sample axis length. `Selection(patches=(k,))` selects a whole patch by index, not a time in seconds. With original sampling rate `f`, its nominal sample interval starts at `k * stride` and spans `patch_samples`; absolute recording/event time must be retained by the caller. No sample-level selector is implied.

| Adapter | Rate | Input patch/sample requirement | Sensor and extent contract |
| --- | ---: | --- | --- |
| CBraMod | 200 Hz | Exactly 200 samples per patch | Uses caller-provided sensor order; no vocabulary remapping. Native checks sample 1, 4 and 5 patches. |
| LaBraM | 200 Hz | Exactly 200 samples per patch | Exact uppercase native channel vocabulary; indices must fit checkpoint embeddings. Time count cannot exceed `max_patches` (16 in tested base checkpoint). |
| CSBrain | 200 Hz | Exactly 200 samples per patch | Exact configured sensor order, restored from native region sorting. Native checks sample 1, 4 and 5 patches. |
| EEGPT | 256 Hz | Patch size and sensor/window counts must equal native configuration; contiguous patches | Native channel lookup is used; no alias inference. Tested checkpoint has 64-sample windows. |
| BIOT | 200 Hz | Container patches concatenate into a continuous signal; stride must equal sample length; total samples at least native `n_fft` | Exact configured complete channel vocabulary/order. Native STFT tokens are not input patches. |
| BENDR encoder/context | 256 Hz | Container patches concatenate, with stride equal to sample length | Exact configured input channels, including any auxiliary scale input. No automatic DN3 preprocessing. Downsampled time is not input patch index. |
| BrainOmni | 256 Hz | Container patches concatenate, with stride equal to sample length | Exact configured channels, explicit native position/direction vectors and sensor-type IDs. Latent sensor units are not electrodes. |
| SignalJEPA | Native `sfreq` (128 Hz tested) | Container patches concatenate; contiguous; total length must survive every native convolution width/stride | Exact configured channel order and unchanged native channel-index mapping. |
| DIVER EEG | 500 Hz | Contiguous 500-sample patches | Exact configured channel order and unchanged explicit xyz geometry. Augmented tokens have no physical selector. |
| ST-EEGFormer | 128 Hz | Contiguous container patches; total length must be divisible by native patch size and fit native time vocabulary | Exact configured channels mapped through supplied native lookup. Tested patch size is 16. |
| NeuroRVQ | 200 Hz | Contiguous 200-sample patches; time count fits native vocabulary | Case-normalized channel lookup; no general alias mapping. Native time indices align to the end of its vocabulary. |

For CBraMod, LaBraM and CSBrain, the adapter currently validates patch sample length but does not prohibit a nondefault stride. Such input is caller-defined; the validated MI recipe uses contiguous patches. Accepted input metadata is not evidence that an overlapping recipe matches a checkpoint's pretraining.

## Feature and physical selections

The final exposed activation axis is the feature axis used by `SubspaceAblation`; its orthonormal basis has shape `[features, rank]`. Changing a dense direction is not the same as deleting an input sensor. Sensor/patch selectors are supported only on verified physical layouts. EEGPT, BIOT, BENDR, SignalJEPA, BrainOmni and ST-EEGFormer conservatively reject physical selectors. DIVER permits them at physical embedding/head sites only. See [model coverage](model-coverage.md) and [dense checks](../validation/DENSE_VALIDATION.md) for exact sites and limitations.

## Boundary evidence and remaining audit items

`validation/validate_mi_boundaries.py` checks official CBraMod, LaBraM and CSBrain checkpoints at two temporal extents each, including LaBraM's maximum 16 patches. All six valid cases exactly match the native adapter forward. Eighteen invalid cases (bad rate, sample count, and applicable channel/extent violations) are rejected before input computation begins; a subsequent valid run exactly reproduces the baseline. Forward/pre-hook cleanup is checked. These are synthetic 19-channel CPU float32 cases, not estimates of scientific validity or universal maxima.

Existing fixture tests cover additional contracts: SignalJEPA convolution receptive field and changed channel mapping, DIVER/BrainOmni coordinate mutation, ST-EEGFormer incomplete patches/configuration changes, and continuous-adapter channel order/overlap rejection. Fixture tests do not replace native checkpoint boundary sweeps for those families.

Native continuous-input extension: both BIOT checkpoints pass at 200/1200 samples; BENDR encoder and full encoder/contextualizer pass at 256/1536 samples; SignalJEPA passes at 384/768 samples. In all ten length cases, repartitioning the same continuous samples into twice as many half-width container patches preserves the native output and every activation cache exactly. Thirty-six invalid-input cases (rate, channel order, overlapping containers, and applicable short-input conditions) are rejected before native forward, followed by exact valid-run recovery. SignalJEPA's checkpoint convolution minimum is additionally derived as 152 samples: that boundary executes with native parity, while 151 is rejected. These CPU float32 checks retain model-owned hooks, including BENDR weight normalization pre-hooks; cleanup means preserving the original hook set, not deleting it. Evidence: `validation/results/continuous-boundaries-v1/` and `validate_continuous_boundaries.py`.

In a4, EEGPT translates unknown native channel names into `ValidationError` and rejects aliases that collide on one native sensor ID. Official checkpoint checks verify four pre-forward rejections (unknown name, duplicate native ID, bad rate, bad window count), exact recovery after each, and unchanged predictions for valid native aliases. BENDR now checks its two-component composition before indexing and rejects malformed components explicitly. Evidence is under `validation/results/adapter-errors-v1/`; dense checks were rerun for both affected adapters.

Known audit gaps remain: some other malformed adapter constructors still expose native Python errors, and not every accepted duration/geometry has checkpoint-backed testing. The package's core `SignalBatch` and intervention errors are validated separately; no claim is made that every malformed architecture or native input currently raises the same exception type.

Native geometry/configuration extension: DIVER EEG and ST-EEGFormer small pass at one and eight native patches (four cases). Eighteen wrong-rate/order/stride/size/extent cases and four mutable-configuration cases are rejected before native computation. DIVER positions are deliberately changed and exactly restored; ST global-pooling configuration is changed and restored. A subsequent valid run matches the baseline exactly. The computation observer is itself required to fire on that valid run, preventing a misplaced hook from falsely proving pre-forward rejection. ST additionally preserves every cache and output when continuous input is equivalently repartitioned. DIVER comparisons pair CPU RNG for native evaluation dropout; arbitrary stochastic equivalence is not implied. Evidence: `validation/results/geometry-boundaries-v1/` and `validate_geometry_boundaries.py`.

NeuroRVQ's official checkpoint now passes native parity at one/eight patches and twelve pre-forward invalid-input cases: wrong rate, overlap, sample size, unknown channel, duplicate native electrode via case aliases, and excess temporal extent. Every rejection is followed by exact four-branch recovery; valid channel-case normalization preserves the output. The source adapter now rejects colliding aliases; the retained a4 wheel predates this fix. Evidence: `validation/results/neurorvq-boundaries-v1.json`.

BrainOmni's tiny checkpoint now has native boundary evidence at 1/512/513/1536 samples. Results exactly match explicit right-padding to 512/512/896/1664 samples under its 512-sample window and 0.25 overlap. Two equivalent container repartitionings preserve every cache/output. Twelve bad-input and twenty window/overlap/position/sensor-type mutation cases are rejected before native sensor computation, followed by exact recovery. A single accepted sample demonstrates native padding semantics, not meaningful EEG inference. Comparisons pair RNG for upstream evaluation dropout. In a5, the adapter records and guards matching model/tokenizer windows and overlap. Evidence: `validation/results/brainomni-boundaries-v1.json`.
