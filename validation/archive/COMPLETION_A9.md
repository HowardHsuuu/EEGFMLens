# Open-source tool completion audit

The acceptance scope is the reusable EEGLens tool. Scientific experiments and
results are maintained separately; an unpublished research replay archive does
not block tool completion.

The [acceptance ledger](PUBLIC_READINESS_A9.md) maps requirements to API documentation,
model conformance evidence, installed-distribution tests, examples and licensing.
The [roadmap](../../docs/roadmap.md) distinguishes implemented functionality from unsupported
future capabilities. No requirement is satisfied merely by an adapter forward
pass or a count of registered model names.

Repository separation requires checking that examples and validation scripts do
not import removed research modules, documentation links remain usable, native
fixture behavior is preserved, and both distribution archives exclude scientific
studies. Historical native evidence remains bound to its original source hashes;
relocation alone is not a new checkpoint validation run.
