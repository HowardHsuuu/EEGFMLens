# Historical validation archive

These records describe earlier versions and environments. They are retained for
traceability, not as current installation instructions or evidence for a new commit.
JSON/XML contents are unchanged, including historical paths and source hashes.
The former vendor audit applies to a9 archives; a10 no longer ships those models.

Use [current validation instructions](../README.md) and [the model guide](../../docs/models.md)
for new runs. Historical source is available at Git revision `94b50a4`.
